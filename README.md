# 예약 클릭 매크로

지정한 시각(밀리초 단위)에 지정한 화면 좌표를 마우스로 클릭하는 프로그램입니다.

## 설치

Python 3.9 이상이 필요합니다.

```bash
pip install -r requirements.txt
```

## 실행

```bash
python click_macro.py
```

## 사용법

1. 신청 페이지를 브라우저에 띄우고 정보를 미리 다 입력해 둡니다.
2. **서버 주소**를 넣고 **서버 측정**을 누릅니다(약 20초). 서버 시차와 **평소 지연**(왕복)이 표시됩니다.
   신청 5~10분 전에 측정하세요.
3. 신청 버튼 위에 마우스를 올리고 **F8**을 눌러 좌표를 저장합니다.
4. **기준 클릭 시각**에 평소 손으로 누르던 서버 시각을 넣습니다. 예: `16:29:59.800`
5. **실시간 지연 보정**을 켜 두고 **최대 보정(ms)** 을 정합니다(기본 200).
6. **예약 시작**을 누르고, 매크로 창이 신청 버튼을 가리지 않게 옮겨 둡니다.
7. **ESC** 또는 **취소** 버튼으로 예약을 취소할 수 있습니다.

## 실시간 지연 보정

정각 직전에는 사람들이 몰리면서 서버 응답이 느려질 수 있습니다. 그래서 기준 클릭 시각을 그날 상황에 맞춰 앞뒤로 움직입니다.

- 클릭 6초 전부터 서버에 요청을 계속 보내 응답 속도(왕복 지연)를 잽니다.
- 최근 5번의 중앙값이 **평소 지연**보다 늘어났으면 그 절반(편도)만큼 **일찍**, 줄었으면 그만큼 **늦게** 누릅니다.
  예: 평소 왕복 40ms, 직전 왕복 160ms → 60ms 일찍 → `59.740`에 클릭
- 보정량은 **최대 보정(ms)** 을 넘지 않습니다. 기준에서 너무 멀리 벗어나 59초로 찍히는 것을 막기 위한 제한입니다.
- 응답이 아예 안 오고 있으면, 그 요청이 기다린 시간만큼은 지연된 것으로 봅니다.
- 진행 중에는 **실시간 지연** 줄에 현재 지연과 예상 클릭 시각이 표시됩니다.

이 방법으로 알 수 있는 건 **클릭 직전까지**의 지연입니다. 정각에 신청이 몰리면서 생기는 대기열 지연은 미리 알 수 없습니다.

## 기록으로 기준 시각 맞추기

매번 실행 결과가 프로그램 옆의 `click_log.csv`에 저장됩니다(엑셀로 열 수 있음).
기준 클릭 시각, 실제 클릭 시각, 보정량, 평소/직전 지연이 남습니다. **결과(직접 기입)** 칸에 당첨 여부와 찍힌 시각을 적어 두세요.
몇 번 쌓이면 지연이 어느 정도일 때 몇 ms에 눌러야 하는지 감이 아니라 기록으로 정할 수 있습니다.

## 서버 시간 측정 원리

- 서버 응답의 `Date` 헤더(초 단위)를 여러 번 받아, 서버 시계의 초가 바뀌는 순간을 좁혀 가며 ms 단위로 시차를 추정합니다.
- 신청 버튼이 실제로 요청을 보내는 주소로 측정하는 것이 가장 정확합니다. 브라우저에서 **F12 → Network** 탭을 열고 페이지를 조작하면 요청 주소가 보입니다.
- 유선 인터넷을 쓰고, 신청 직전에는 다운로드나 영상 재생을 끄세요.

## 정확도

- 목표 시각 20ms 전까지는 sleep으로 기다리고, 그 이후에는 busy-wait으로 대기해서 보통 1ms 이내로 클릭합니다.
- 클릭 전에 커서를 미리 목표 좌표로 옮겨 둡니다.
- Windows에서는 타이머 해상도를 1ms로 설정하고 DPI 배율을 인식하도록 설정합니다.

## 참고

- macOS에서는 시스템 설정 → 개인정보 보호 및 보안 → **손쉬운 사용** 및 **입력 모니터링**에서 터미널(또는 Python)을 허용해야 합니다.
- 관리자 권한으로 실행된 프로그램을 클릭하려면 이 매크로도 관리자 권한으로 실행해야 할 수 있습니다.
- 플랫폼 이용약관에서 매크로 사용을 금지할 수 있습니다. 사용 전에 확인하세요.
