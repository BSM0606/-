# 예약 클릭 매크로

지정한 시각(밀리초 단위)에 지정한 화면 좌표를 마우스로 클릭하는 프로그램입니다.

## 설치

Python 3.9 이상이 필요합니다.

```bash
pip install -r requirements.txt
```

## 실행

```bash
python click_macro.py
```

## 사용법

1. 신청 페이지를 브라우저에 띄우고 정보를 미리 다 입력해 둡니다.
2. **서버 주소**에 신청 사이트 주소(기본값 `https://berriz.in`)를 넣고 **서버 시간 측정**을 누릅니다. 약 20초가 걸리며, 끝나면 PC와 서버의 시차가 표시됩니다.
   빨간색 **서버 시각**이 이제 서버 기준 시각입니다.
3. 신청 버튼 위에 마우스를 올리고 **F8**을 눌러 좌표를 저장합니다.
4. **예약 시각**에 서버 기준 `HH:MM:SS.mmm`을 입력합니다. 예: `16:30:00.000`
5. **예약 시작**을 누르고, 매크로 창이 신청 버튼을 가리지 않게 옮겨 둡니다.
6. **ESC** 또는 **취소** 버튼으로 예약을 취소할 수 있습니다.

클릭이 끝나면 클릭한 서버 시각과 오차가 화면 아래에 표시됩니다.

## 서버 시간 측정 원리와 보정

- 서버 응답의 `Date` 헤더는 초 단위라서, 요청을 여러 번 보내 서버 시계의 초가 바뀌는 순간을 좁혀 가며 ms 단위 시차를 추정합니다.
- 결과의 **오차 ±N ms**는 측정 불확실성입니다. 너무 이르면(29:59) 실패하므로 **추가 보정(ms)** 에 오차만큼 양수(예: `+20`)를 넣어 살짝 늦게 누르는 것이 안전합니다.
  클릭 후 요청이 서버에 도착하기까지 네트워크 지연이 더해지므로, 보통은 정각에 맞춰 눌러도 서버에는 정각 직후로 기록됩니다.
- 예약 직전(5~10분 전)에 한 번 더 측정하면 더 정확합니다.
- 주소 서버의 시계가 실제 신청을 처리하는 서버의 시계와 다를 수 있습니다(CDN 등). 가능하면 신청 페이지 주소로 측정하세요.

## 정확도

- 목표 시각 20ms 전까지는 sleep으로 기다리고, 그 이후에는 busy-wait으로 대기해서 보통 1ms 이내로 클릭합니다.
- 클릭 1초 전에 커서를 미리 목표 좌표로 옮겨 둡니다.
- Windows에서는 타이머 해상도를 1ms로 설정하고 DPI 배율을 인식하도록 설정합니다.

## 참고

- macOS에서는 시스템 설정 → 개인정보 보호 및 보안 → **손쉬운 사용** 및 **입력 모니터링**에서 터미널(또는 Python)을 허용해야 합니다.
- 관리자 권한으로 실행된 프로그램을 클릭하려면 이 매크로도 관리자 권한으로 실행해야 할 수 있습니다.
- 플랫폼 이용약관에서 매크로 사용을 금지할 수 있습니다. 사용 전에 확인하세요.
