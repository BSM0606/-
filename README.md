# 예약 클릭 매크로

지정한 시각(밀리초 단위)에 지정한 화면 좌표를 마우스로 클릭하는 프로그램입니다.

## 설치

Python 3.9 이상이 필요합니다.

```bash
pip install -r requirements.txt
```

## 실행

```bash
python click_macro.py
```

## 사용법

1. 클릭할 위치에 마우스를 올리고 **F8**을 누르면 좌표가 저장됩니다. X, Y 칸에 직접 입력해도 됩니다.
2. **예약 시각**에 `HH:MM:SS.mmm` 형식으로 입력합니다. 예: `20:00:00.000`
3. 필요하면 **보정(ms)** 값을 넣습니다. `-100`을 넣으면 100ms 일찍 클릭합니다.
   PC 시계와 서버 시계가 다를 때 사용합니다.
4. 버튼 종류, 클릭 횟수, 클릭 간격(ms)을 정하고 **예약 시작**을 누릅니다.
5. **ESC** 또는 **취소** 버튼으로 예약을 취소할 수 있습니다.

클릭이 끝나면 실제 클릭 시각과 목표 시각의 오차가 화면 아래에 표시됩니다.

## 정확도

- 목표 시각 20ms 전까지는 sleep으로 기다리고, 그 이후에는 busy-wait으로 대기해서 보통 1ms 이내로 클릭합니다.
- 클릭 1초 전에 커서를 미리 목표 좌표로 옮겨 둡니다.
- Windows에서는 타이머 해상도를 1ms로 설정하고 DPI 배율을 인식하도록 설정합니다.
- 기준 시계는 PC 시계입니다. 정확한 시각이 중요하면 Windows 설정 → 시간 및 언어 → **지금 동기화**로 PC 시계를 먼저 맞춰 두세요.

## 참고

- macOS에서는 시스템 설정 → 개인정보 보호 및 보안 → **손쉬운 사용** 및 **입력 모니터링**에서 터미널(또는 Python)을 허용해야 합니다.
- 관리자 권한으로 실행된 프로그램을 클릭하려면 이 매크로도 관리자 권한으로 실행해야 할 수 있습니다.
