# 예약 클릭 매크로

지정한 시각(밀리초 단위)에 지정한 화면 좌표를 마우스로 클릭하는 프로그램입니다.

## 설치

Python 3.9 이상이 필요합니다.

```bash
pip install -r requirements.txt
```

## 실행

```bash
python click_macro.py
```

## 사용법

1. 신청 페이지를 브라우저에 띄우고 정보를 미리 다 입력해 둡니다.
2. **서버 주소**에 신청 사이트 주소(기본값 `https://berriz.in`)를 넣고 **서버 측정**을 누릅니다. 약 20초가 걸립니다.
   끝나면 서버 시차, 네트워크 지연(왕복/편도)이 표시되고 **안전 여유**가 자동으로 입력됩니다.
3. 신청 버튼 위에 마우스를 올리고 **F8**을 눌러 좌표를 저장합니다.
4. **도착 목표 시각**에 서버 기준 `HH:MM:SS.mmm`을 입력합니다. 예: `16:30:00.000`
5. **예약 시작**을 누르면 실제로 언제 클릭할지(예: `16:29:59.957에 클릭 (43ms 일찍)`)가 표시됩니다.
   매크로 창이 신청 버튼을 가리지 않게 옮겨 둡니다.
6. **ESC** 또는 **취소** 버튼으로 예약을 취소할 수 있습니다.

## 클릭 시각 계산

손으로 59.8~59.9초에 누르던 것을 자동으로 계산합니다.

```
클릭 시각(PC) = 도착 목표(서버) − 서버 시차 − 네트워크 편도 지연 − 브라우저 지연 + 안전 여유
```

- **서버 시차**: 서버 응답의 `Date` 헤더(초 단위)를 여러 번 받아, 서버 시계의 초가 바뀌는 순간을 좁혀 가며 ms 단위로 추정합니다.
- **네트워크 편도 지연**: 서버 측정 때 잰 왕복 지연(RTT) 중앙값의 절반입니다. 회선 상태는 계속 변하므로 **클릭 10초 전에 다시 측정**해서 클릭 시각을 갱신합니다.
- **브라우저 지연**: 버튼을 클릭한 뒤 브라우저가 요청을 보내기까지의 시간입니다. 측정할 방법이 없어 기본값 0이며, 경험상 필요하면 10~30 정도를 넣습니다.
- **안전 여유**: 측정 오차(시차 오차 + 지연 흔들림)만큼 살짝 늦게 눌러서, 목표 시각보다 일찍(예: 59초) 도착하는 일을 막습니다. 측정 후 자동 입력되며, 직접 바꿀 수 있습니다.

### 더 정확하게 쓰려면

- 신청 버튼이 실제로 요청을 보내는 주소로 측정하세요. 브라우저에서 **F12 → Network** 탭을 연 상태로 아무 동작을 해 보면 요청 주소(예: `https://api.xxx.com/...`)가 보입니다. 그 주소의 도메인을 **서버 주소**에 넣으면 됩니다.
- 유선 인터넷이 무선보다 지연 흔들림이 훨씬 작습니다.
- 신청 직전에는 다운로드나 영상 스트리밍처럼 회선을 많이 쓰는 작업을 끄세요.
- 브라우저가 서버와의 연결을 오래 쓰지 않으면 연결이 끊겨, 클릭 순간 재연결 때문에 수십 ms가 더 걸릴 수 있습니다. 신청 1~2분 전에 페이지 안에서 입력 내용이 사라지지 않는 가벼운 동작(스크롤 등)을 해 두는 것이 좋습니다.
- 지난번 결과를 보고 조정하세요. 너무 늦게 찍혔으면 안전 여유를 줄이고, 59초로 찍혔으면 늘립니다.

## 정확도

- 목표 시각 20ms 전까지는 sleep으로 기다리고, 그 이후에는 busy-wait으로 대기해서 보통 1ms 이내로 클릭합니다.
- 클릭 1초 전에 커서를 미리 목표 좌표로 옮겨 둡니다.
- Windows에서는 타이머 해상도를 1ms로 설정하고 DPI 배율을 인식하도록 설정합니다.

## 참고

- macOS에서는 시스템 설정 → 개인정보 보호 및 보안 → **손쉬운 사용** 및 **입력 모니터링**에서 터미널(또는 Python)을 허용해야 합니다.
- 관리자 권한으로 실행된 프로그램을 클릭하려면 이 매크로도 관리자 권한으로 실행해야 할 수 있습니다.
- 플랫폼 이용약관에서 매크로 사용을 금지할 수 있습니다. 사용 전에 확인하세요.
